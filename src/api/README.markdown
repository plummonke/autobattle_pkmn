# PokeAPI Service

## Congfiguration
This API uses a JSON encoded file for configuration. The file must have the following data:

| key | description | value type |
| :-- | :-- | :-- |
| base\_url | URL for the API. | str |
| endpoint\_file | Filename for the JSON file containing API endpoint data | str | 
| cache | Base filename for the cache file. | str |
